# email-signature

Stopki e-mail Programy Dla Klubów.

## pdk-2026 (nowy design system PDK, 6.11.2026)

- `pdk-2026/stopka-piotr-bak.html` - stopka do wklejenia (obrazki z tego repo, adresy raw.githubusercontent.com)
- `pdk-2026/podglad.png` - jak wygląda
- logo i ikony wygenerowane z design systemu PDK (`assets/logo/pdk-logo-poziome-kolor.svg`, `icons/icons.json`)

Wklejanie: otwórz `stopka-piotr-bak.html` w Chrome, Cmd+A, Cmd+C, wklej w ustawieniach podpisu programu pocztowego.

Stare pliki (`LOGO PROGRAMY DLA KLUBOW.png`, `PITER.png`) zostają, bo używają ich wysłane już maile.
